# Codebook history

How the classification bar changed, commit by commit. The "codebook" is the bar and its decision rules as written in three tracked files: [`METHODOLOGY.md`](METHODOLOGY.md), [`SOURCES.md`](SOURCES.md) and [`data/stage_definitions.json`](data/stage_definitions.json). This file is a record, not a rule: it changes no stage, row or rule, and the current bar is always the one in those three files.

A rule was sometimes written down while rows were being reviewed under it, or after a review pass had already applied it. Readers comparing labels across review dates need to know which written bar was in force when a row was first ruled. This file gives that, from the git history alone.

## Method

`git log --full-history` on the three files (11 commits touch them), `git show` of each diff, and `git log -S` for the first appearance of key phrases. A change counts when it alters what qualifies for a stage, how ties or absence of evidence are handled, how confidence is assigned, what counts as evidence or a source tier, or what is in scope. Review times come from `data/first_review.jsonl`. To check any row: `git show <commit> -- <file>`.
